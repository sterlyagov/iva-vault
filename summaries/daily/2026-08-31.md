# 2026-08-31

## Topics

- **Манжерок и таксопарк** — оценивалась потребность в водителях для зимних трансферов из аэропорта Горно-Алтайска.
- **Групповой Telegram-чат** — проверена работа Ивы с другими участниками и обнаружено ограничение списка разрешённых пользователей.
- **Возможности Ивы** — разобраны примеры помощи в работе, личных делах, документах и подключаемых сервисах.
- **Напоминание** — настройка Apple ID дочери перенесена на 1 сентября, 20:00 по Омску.

## Highlights

- Для трансферов предложена модель с постоянным ядром водителей и резервом под пики прилётов.
- Личная Ива отвечает только разрешённым пользователям; для общего чата безопаснее отдельный бот без доступа к личным данным и инструментам.
- После повторного вопроса уточнена настоящая причина отсутствия ответа другому участнику группы.
