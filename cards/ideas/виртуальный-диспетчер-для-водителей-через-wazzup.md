# Виртуальный диспетчер для водителей через Wazzup

Александр выбрал чтение всех каналов Wazzup через защищённый read-only API taxibalans.ru вместо пересылки webhook. 19 октября 2026 на сервере Ивы был установлен токен, проверено получение событий и активирован управляемый автоопрос одной страницы до 100 событий каждую минуту. После догрузки доступная API-история составила 1627 событий за 17–19 октября 2026; это не архив за год. В переписках преимущественно водители, но есть сообщения ботов и редкие клиентские обращения по корпоративным заказам Сбербанка в Омске: перед подсказками необходимо различать тип собеседника и не принимать клиентские сообщения за водительские. Цель — анализировать типовые вопросы и ответы, затем предлагать черновики человеку; самостоятельная отправка ответов не разрешена, обучение весов модели не включено. 21 октября Александр разрешил передавать настроенному провайдеру модели необезличенные данные переписок для ограниченного теста смыслового анализа, но не для постоянной передачи всей базы. Владелец ранее запросил ежедневный отчёт в 09:00 по Омску и тестовые ответы по новым диалогам отдельными сообщениями в этом чате. Владелец подтвердил WAZZUP_KEEP_DAYS=365 в файле конфигурации сайта; факт выполнения очистки на сайте не проверен. 22 октября по просьбе Александра локальные Wazzup-плагины Ивы остановлены, ежедневный отчёт отменён, а локальные каталоги данных Wazzup с базами и учётными ключами удалены с сервера Ивы. Сбор и инициативные сообщения Wazzup приостановлены до нового явного разрешения; база и интеграция taxibalans.ru не затронуты.
