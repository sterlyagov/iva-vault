# ИИ-помощник для водителей

Владелец хочет изучить функции приложений для водителей Яндекс Такси и способы встроить ИИ-агента, помогающего водителям. Этапы работы Ивы: изучение переписок без отправки сообщений, затем подсказки диспетчеру и только после разрешения директора самостоятельные ответы через taxibalans.ru. Владелец задал ежедневный короткий отчёт по частым вопросам, противоречиям, проблемам и идеям с примерами без лишних телефонов. Владелец предложил начать ИИ-анализ переписок и попросил доработать и установить подключение модели. Все сообщения приходят на сервер Ивы. Для тестовых запросов владелец пока не ограничивает бюджет, разрешил отправлять обычные данные и заявил, что берёт на себя риски теста.
