# Голосовые ответы Ивы через OpenAI TTS

1 сентября 2026 года OpenAI TTS был подключён для исходящих голосовых ответов: выбран голос marin, формат предназначен для Telegram, а голосовое должно дополнять текстовый ответ и работать только в личном чате. На API-аккаунте закончились кредиты, поэтому фактический тест не прошёл. Для включения требуется пополнить баланс и выполнить перезапуск Ивы. В личном чате пользователя автоматические голосовые ответы должны быть отключены; голосовое отправляется только по прямой просьбе.
