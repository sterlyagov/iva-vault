# Подписка ChatGPT не оплачивает OpenAI API

Генерация изображений в приложении ChatGPT работает в рамках условий приложения, подписки или доступного лимита. Ива на сервере обращается к OpenAI Images через API, для которого нужны отдельный ключ и отдельный API-баланс. Наличие доступа к картинкам в ChatGPT само по себе не даёт API-кредиты.
