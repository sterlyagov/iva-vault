## 13:36 [iva]
Шеф, Git сообщает, что локальная ветка `master` ещё не связана с удалённой веткой.

Выполни:

```bash
git push --set-upstream origin master
```

После этого обычный `git push` будет работать без дополнительных параметров.

Перед отправкой можно проверить remote:

```bash
git remote -v
```

Если ветка на сервере должна называться `main`, используй:

```bash
git push --set-upstream origin master:main
```
